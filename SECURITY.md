# Security Policy

## Public Portfolio Boundary

This repository contains synthetic data and a demonstration webhook implementation. Do not open an issue, discussion, or pull request containing live credentials, phone numbers, customer messages, webhook payloads, ticket exports, or internal infrastructure details.

## Reporting a Concern

Use the private contact route on [Ramphal Harrilal's portfolio](https://ramphalharrilal.github.io/) instead of a public issue when a report may contain security-sensitive information. Share the minimum detail required to identify the affected component and behavior.

## Supported Demonstration Version

The latest commit on `main` is the supported portfolio version. This project is not represented as a hosted production support service.

## Required Production Review

Before production use, complete an independent application-security, privacy, threat-modeling, data-retention, Meta compliance, authentication, authorization, monitoring, and incident-response review.
